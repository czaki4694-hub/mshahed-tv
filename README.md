# مِشاهِد | Mshahed TV

واجهة PWA عربية RTL لكتالوج قنوات تلفزيونية، مستوحاة من صورة القنوات المرفقة.

## الموجود في هذه النسخة
- تصميم متجاوب للهاتف والكمبيوتر.
- قنوات المغرب التجريبية مع تصنيفات.
- بحث فوري.
- مفضلة محفوظة على الجهاز.
- نافذة مشغّل فيديو.
- دعم التثبيت كتطبيق PWA والعمل الأساسي دون اتصال بعد أول زيارة.

## تشغيل المشروع
افتح `index.html` في متصفح حديث، أو شغّل خادماً محلياً بسيطاً. بعض خصائص PWA تحتاج HTTPS أو localhost.

## نشره على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub باسم `mshahed-tv`.
2. ارفع جميع ملفات هذا المجلد إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
5. انتظر رابط النشر الذي يظهر في صفحة Pages.

## إضافة رابط بث مرخّص
في `app.js` أضف خاصية `stream` إلى القناة التي تملك حق بثها، مثلاً:
```js
{id:13, name:"قناة تجريبية", country:"المغرب", category:"general",
 logo:"TV", style:"blue", desc:"قناة مرخصة",
 stream:"https://your-authorized-provider.example/live.m3u8"}
```
لا تضع روابط بث لا تملك ترخيصاً لاستخدامها. دعم HLS يختلف حسب المتصفح؛ قد نضيف مكتبة HLS مخصصة في مرحلة لاحقة.

## المرحلة التالية: لوحة الإدارة والخادم
GitHub Pages يستضيف الواجهة الثابتة فقط، ولا يشغّل قاعدة بيانات أو API آمن. لإدارة القنوات والمباريات من لوحة خاصة، سنضيف لاحقاً:
- Backend API (مثلاً Node.js).
- قاعدة بيانات للقنوات والمباريات.
- تسجيل دخول آمن بصلاحيات مدير.
- رفع شعارات وصور.
- سجل تغييرات ونسخ احتياطية.
- تخزين روابط البث المرخّصة في الخادم، لا في مستودع GitHub العام.

## ملاحظة
القنوات والأسماء المعروضة بيانات تجريبية لتوضيح التصميم فقط. هذا المشروع لا يتضمن بثاً أو روابط سيرفرات.
